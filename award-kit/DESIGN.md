# Design System — Award Kit

## Colours
- **Primary:** Deep charcoal and near-black surfaces
- **Secondary:** Warm cream backgrounds
- **Neutral:** Soft greys for rules and supporting text
- **Background:** Alternating cream and dark editorial panels
- **Text:** Charcoal, white, and muted grey depending on theme

## Typography
- **Headings:** Swiss Posters for compressed, high-impact display moments
- **Body:** Inter Tight for editorial reading
- **Monospace:** DM Mono for metadata, labels, and results

## Aesthetic Direction
Editorial, modernist, awards-showcase, cinematic, precise.

## References
- Existing extracted award entry experience in this repo — use as the baseline visual language

## Don'ts
- Do not introduce generic SaaS styling
- Do not swap the extracted font stack for system defaults
- Do not flatten the light/dark thematic contrast

## Component Notes
- The packaged app should preserve the extracted award-entry presentation and only add minimal shell UI around it.
