# Surface — "What matters now."

## Scope and mode

Route `/surface` (default landing). Mode: **Read** — the visitor's success is
understanding what matters for the analysis context, fast enough to say it
aloud in a client meeting.

## Audience, job, task

Apparent strategists and analysts. Primary scene: all three confirmed
2026-08-07 — pre-client-meeting brief first, presentable enough to
screen-share, scannable week over week. Job: absorb the lead analysis, scan
momentum, expand one current to its markers. Primary action: expanding a
current row.

## Proof / content

Fixture data only in this phase (Audi · Premium Automotive · Australia ·
EV Intenders · last 90 days), labelled FIXTURE everywhere a viewer could
mistake it for live evidence. Semrush is the only connectable source; others
labelled honestly.

## Chosen direction

**Apparent Red Terminal** (user-pinned 2026-08-07, third steer — replaced
the rolled split-flap board and the synoptic bulletin, which read as trying
too hard to be weather). The Apparent site system carries the product: cream
ground, red as the working colour (DM Mono uppercase labels, hairline red
rules, pill chips/controls, red circular action buttons), Inter Tight only
(400 copy / 500 sentence-case headlines; Swiss Posters retired). Data lives
in rounded charcoal terminal panels with red numerics — the site's LED
market-board register (dashboard density referenced from the user's two
dashboard images, but never blue-SaaS). Cream + charcoal panels confirmed
over a dark surface.

Memorable moment: the charcoal momentum panel — five currents as red bar
series with large red momentum figures, rising once on load.

## Constraints

Brand commitments pinned (lockup + Currents header, Inter Tight two-weight
system, palette incl. --color-red-text AA ramp). Never the phrase "read the
water". No colour-only meaning; reduced-motion support; desktop primary,
concise mobile summary.
